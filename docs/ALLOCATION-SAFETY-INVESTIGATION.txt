New diagnostic tool
-------------------
analysis/actual-migration-preflight/readonly-audit.py is a separate diagnostic
reader, not a migration admission path. It pins the unchanged reviewed identity
guard and crypto helper. Both handles are opened GENERIC_READ; both exact serial,
size, USB and sector identities pass before local key derivation. No key material
is logged, hashed or exported. The original small probe's32KiB budget is unchanged.

The diagnostic uses a separately bounded metadata capture: at most1GiB plaintext
metadata retained on host and2GiB aligned raw reads including stability replay.
It reads maps, allocated inode records, directories and indirect blocks, plus at
most8 one-fragment samples of unidentified allocations. It does not hash regular
file payloads or materialize sparse holes. Progress is flushed NDJSON. Every
captured metadata page is reread and compared before reporting completion.
Capture-size/bounds errors stop the audit; no partial result qualifies readiness.
The output is always diagnostic_only=true and migration_admitted=false.
Fragment-run/cluster summaries and PS3 runtime correctness are not qualified.
